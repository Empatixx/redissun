---
title: SortedSet
description: Values ordered by a score, shared across programs.
---

A `SortedSet` keeps values ordered by a score. Use it for leaderboards, priority queues and time lines.

```rust
let board = client.sorted_set::<String>("scores");

board.insert("ann", 12.0).await?;
board.add_score("ann", 3.0).await?;
let best = board.last().await?;
let top3 = board.rev_range(0..3).await?;
```

Values with the same score are ordered by their encoded bytes. Values are equal when their encoded bytes are equal.

## Methods

| Method | Notes |
|---|---|
| `insert(&v, score)` | returns `true` when the value is new. An old value gets the new score. |
| `add_score(&v, delta)` | returns the new score. A missing value starts from 0. |
| `score(&v)`, `rank(&v)`, `rev_rank(&v)` | rank 0 is the lowest score, or the highest for `rev_rank` |
| `remove(&v)`, `contains(&v)` | |
| `len()`, `is_empty()`, `clear()` | |
| `first()`, `last()` | read without removing |
| `pop_first()`, `pop_last()` | remove and return, one owner gets each value |
| `pop_first_wait()`, `pop_last_wait()` | wait for a value. Add `.timeout(wait)` to get `None` when `wait` runs out. |
| `range(a..b)`, `rev_range(a..b)` | by position. The end is exclusive, like a slice. |
| `range_by_score(a..=b)` | any `f64` range: `1.0..`, `..=3.0`, `..`, or `(Bound::Excluded(a), Bound::Included(b))` |
| `count_by_score(range)`, `remove_by_score(range)` | |
| `iter()` | a stream of `(value, score)` read with `ZSCAN`; the order is not guaranteed |

Values come back with their score as `(V, f64)`. `SortedSet` also has the `Object` methods.

## Priority queue

`pop_first()` is atomic, so many workers can take the lowest score without getting the same value twice. When the set is empty it returns `None`. `pop_first_wait()` waits for a value instead. A waiting call uses its own short-lived connection, like the blocking pops of `VecDeque`.

A value is in the set once. Pushing it again only changes its priority.
