---
title: AtomicI64
description: A shared counter.
---

An `AtomicI64` is a number in a Redis string. A missing counter reads as 0.

```rust
let visits = client.atomic_i64("visits");

let total = visits.incr().await?;
visits.add(10).await?;
```

## Methods

Every method is `async` and returns `redissun::Result<T>`. The **Returns** column shows `T`, the value inside `Ok`. `()` means the call has no value to give back, only success or an error, so `?` passes the error on and drops the `()`.

| Method | Redis command | Returns |
|---|---|---|
| `get()` | `GET` | the value, 0 if missing |
| `set(v)` | `SET` | `()` |
| `swap(v)` | `GETSET` | the old value |
| `take()` | Lua script | the old value |
| `compare_and_set(expected, update)` | Lua script | `true` if the value was changed |
| `compare_and_delete(comparison, threshold)` | Lua script | `true` if the counter was deleted |
| `set_if_less(less, v)` and `set_if_greater(greater, v)` | Lua script | `true` if the value was changed |
| `add(delta)` | `INCRBY` | the new value |
| `fetch_add(delta)` | `INCRBY` | the value before; `fetch_add(1)` is Redisson's `getAndIncrement` |
| `incr()` and `decr()` | `INCR`, `DECR` | the new value |

`compare_and_set`, `set_if_less` and `set_if_greater` treat a missing counter as 0, like Redisson. `compare_and_delete` takes a `Comparison` (`Less`, `LessOrEqual`, `Greater`, `GreaterOrEqual`, `Equal` or `NotEqual`) and never deletes a missing counter. `set`, `swap` and `compare_and_set` replace the value the way Redis `SET` does, so they also remove a time limit set with `expire`. `incr`, `decr`, `add` and `fetch_add` keep it.

The value is stored as a plain integer, not through the codec. Other tools can read it. If the key holds something that is not an integer, the call returns an error.
