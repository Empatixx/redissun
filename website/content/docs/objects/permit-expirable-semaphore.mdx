---
title: PermitExpirableSemaphore
description: A semaphore whose permits have ids and leases, so permits of a crashed program come back.
---

A `PermitExpirableSemaphore` is a semaphore whose every permit has an id, like Redisson's `RPermitExpirableSemaphore`. You release a permit by its id. A permit taken with a lease returns to the semaphore by itself when the lease ends, so the permits of a program that crashed are not lost, as they are with [`Semaphore`](./semaphore).

```rust
let slots = client.permit_expirable_semaphore("render-slots");
slots.init_permits(4).await?;

let id = slots.acquire().lease(Duration::from_secs(30)).await?;
// … render …
slots.release(&id).await?;
```

## Methods

| Method | Notes |
|---|---|
| `acquire()` | waits for a permit and returns its id; add `.lease(d)` and `.timeout(wait)` |
| `acquire_many(n)` | waits for `n` permits and returns their ids |
| `try_acquire()`, `try_acquire_many(n)` | only when the permits are free now |
| `release(&id)`, `release_many(&ids)` | fail with `Error::PermitNotHeld` when a permit is not held |
| `try_release(&id)`, `try_release_many(&ids)` | return whether, or how many, were released |
| `update_lease(&id, Some(d))` | gives a held permit a new lease from now; `None` removes it |
| `lease_time(&id)` | the time left, `None` without a lease |
| `init_permits(n)` | only when the semaphore does not exist yet |
| `set_permits(n)` | the number of permits, free and held together |
| `add_permits(n)` | adds free permits; a negative number takes them away |
| `available_permits()`, `acquired_permits()`, `permits()` | free, held, and both together |

A permit id is 32 hex digits. `release_many` and `try_release_many` release nothing when one of the ids is not held.

## Good to know

- A permit whose lease ended returns when the semaphore is next used. A waiter tries again when the first lease ends, so it gets the permit on time.
- Lease times come from the clock of the program that takes the permit, as in Redisson. Keep the clocks of your servers in sync.
- An `acquire` that is cancelled after it took permits releases them.
- The free permits live in a string named like the semaphore and the held ids in the sorted set `{name}:timeout`. `del`, `expire` and `rename` change both.
