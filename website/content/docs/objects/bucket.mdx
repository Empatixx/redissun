---
title: Bucket
description: One value under one key.
---

A `Bucket` keeps one value in a Redis string.

```rust
let bucket = client.bucket::<String>("greeting");

bucket.set("hello").await?;
let value = bucket.get().await?;
```

## Methods

Every method is `async` and returns `redissun::Result<T>`. The **Returns** column shows `T`, the value inside `Ok`. `()` means the call has no value to give back, only success or an error, so `?` passes the error on and drops the `()`.

| Method | Redis command | Returns |
|---|---|---|
| `set(&v)` | `SET` | `()` |
| `get()` | `GET` | `Option<V>` |
| `set_ex(&v, ttl)` | `SET PX` | `()` |
| `set_nx(&v)` | `SET NX` | `true` if the value was stored |
| `get_set(&v)` | `GETSET` | the old value |
| `get_del()` | Lua script | the removed value |
| `compare_and_set(Some(&expected), Some(&new))` | Lua script | `true` if the value was changed. `None` as expected means "only if missing"; `None` as new deletes the key. |


Values are passed by reference. For a `Bucket<String>` you can pass a `&str` such as `bucket.set("hello")`, or a `&String`.

A time limit must be longer than zero. Very small limits are rounded up to one millisecond.

## Methods for the key

Every object (`Bucket`, `HashMap`, `Vec`, `VecDeque`, `HashSet`, `HashMapCache`, `Lock`, `AtomicI64`, `Semaphore`, `CountDownLatch`, `RateLimiter`) has the `Object` methods:

| Method | Redis command |
|---|---|
| `name()` | the key name |
| `del()` | `DEL` |
| `exists()` | `EXISTS` |
| `rename(new_name)` | `RENAME` |
| `expire(ttl)` | `PEXPIRE` |
| `ttl()` | `PTTL`. It is `None` if there is no time limit. |
| `persist()` | `PERSIST` |

Add `use redissun::Object;` to call them.
