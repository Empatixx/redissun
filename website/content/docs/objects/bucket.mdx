---
title: Bucket
description: One value under one key.
---

A `Bucket` keeps one value in a Redis string.

```rust
let bucket = client.bucket::<String>("greeting");

bucket.set(&"hello".to_string()).await?;
let value = bucket.get().await?;
```

## Methods

| Method | Redis command | Returns |
|---|---|---|
| `set(&v)` | `SET` | nothing |
| `get()` | `GET` | `Option<V>` |
| `set_ex(&v, ttl)` | `SET PX` | nothing |
| `set_nx(&v)` | `SET NX` | `true` if the value was stored |
| `get_set(&v)` | `SET GET` | the old value |
| `get_del()` | `GETDEL` | the removed value |
| `compare_and_set(&expected, &new)` | Lua script | `true` if the value was changed |

`get_set` and `get_del` need Redis 6.2 or newer.

A time limit must be longer than zero. Very small limits are rounded up to one millisecond.

## Methods for the key

Every object (`Bucket`, `Map`, `Lock`, `AtomicLong`, `Semaphore`, `CountDownLatch`, `RateLimiter`) has the `Object` methods:

| Method | Redis command |
|---|---|
| `name()` | the key name |
| `del()` | `DEL` |
| `exists()` | `EXISTS` |
| `rename(new_name)` | `RENAME` |
| `expire(ttl)` | `PEXPIRE` |
| `ttl()` | `PTTL`. It is `None` if there is no time limit. |
| `persist()` | `PERSIST` |

Add `use redissun::Object;` to call them.
