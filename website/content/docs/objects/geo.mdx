---
title: Geo
description: Members with a position, and searches around a point.
---

A `Geo` keeps members with a position on Earth. You can ask for the distance between members and for the members near a point.

```rust
use redissun::{GeoOrder, GeoPoint, GeoSearch, GeoUnit};

let shops = client.geo::<String>("shops");
shops.insert("prague", GeoPoint { longitude: 14.4378, latitude: 50.0755 }).await?;

let near = shops
    .search(GeoPoint { longitude: 14.4, latitude: 50.1 }, &GeoSearch::radius(5.0, GeoUnit::Kilometers).order(GeoOrder::Asc))
    .await?;
for found in near {
    println!("{} is {:.1} km away", found.value, found.distance);
}
```

## Methods

| Method | Notes |
|---|---|
| `insert(&v, point)` | returns `true` for a new member. An old member moves. |
| `try_insert(&v, point)` | adds only a missing member (`GEOADD NX`) |
| `update(&v, point)` | moves only an existing member; returns whether it was there |
| `extend(entries)` | adds or moves many members; returns how many were new |
| `remove(&v)`, `position(&v)`, `positions(&[&v])` | positions are `Option<GeoPoint>` |
| `geohash(&v)`, `geohash_many(&[&v])` | the 11 character geohash |
| `distance(&a, &b, unit)` | `None` when a member is missing |
| `search(point, &args)` | members found around a point, each as a `GeoMatch` with `value`, `distance` and `point` |
| `search_from(&v, &args)` | around another member. The member itself is included. |
| `store_search(dest, point, &args)`, `store_search_from(dest, &v, &args)` | store the found members in another geo set (`GEOSEARCHSTORE`) |
| `to_vec()` | all members in geohash order |
| `len()`, `is_empty()`, `clear()` | |

`args` is a `GeoSearch`: `GeoSearch::radius(r, unit)` or `GeoSearch::rect(width, height, unit)`, then `.order(GeoOrder::Asc)`, `.count(n)` to limit how many members a search returns, and `.store_dist()` for stores. Units are `GeoUnit::{Meters, Kilometers, Miles, Feet}`.

Longitude must be within 180 and latitude within 85.05112878 degrees, otherwise the call is `Error::Config`. Positions are stored with a precision of about 0.6 millimeters, so a position you read back can differ in the last digits. Searches need Redis 6.2 or newer.

## Redis keys

One sorted set `{name}` that uses the Redis geo commands, so `redis-cli` can read it too. Members go through the codec, so with the JSON codec a member `prague` is stored as `"prague"` with the quotes.
