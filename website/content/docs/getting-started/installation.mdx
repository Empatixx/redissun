---
title: Installation
description: Add redissun to your project.
---

redissun is not on crates.io yet. Add it from Git:

```toml
[dependencies]
redissun = { git = "https://github.com/Empatixx/redissun" }
tokio = { version = "1", features = ["full"] }
serde = { version = "1", features = ["derive"] }
```

You also need a Redis server, version 6.2 or newer. To start one with Docker:

```bash
docker run --rm -p 6379:6379 redis:7.4
```

## Run the tests

The tests start Redis with Docker. Docker must be running. If you use Colima, point `DOCKER_HOST` to its socket:

```bash
DOCKER_HOST=unix:///path/to/docker.sock cargo test
```

To use a Redis server that already runs, set `REDISSUN_TEST_REDIS_URL`:

```bash
REDISSUN_TEST_REDIS_URL=redis://localhost:6379 cargo test
```
