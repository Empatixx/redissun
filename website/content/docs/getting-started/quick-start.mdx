---
title: Quick Start
description: Connect, store a value, use a map and take a lock.
---

```rust
use redissun::{Client, Object};
use serde::{Deserialize, Serialize};

#[derive(Serialize, Deserialize)]
struct User {
    name: String,
}

#[tokio::main]
async fn main() -> redissun::Result<()> {
    let client = Client::builder().url("redis://127.0.0.1:6379").build().await?;

    let motd = client.bucket::<String>("motd");
    motd.set(&"hello".to_string()).await?;

    let users = client.map::<String, User>("users");
    users.insert("jirka".into(), User { name: "Jirka".into() }).await?;
    let found = users.get("jirka").await?;

    let lock = client.lock("order:42");
    let guard = lock.lock().await?;
    guard.unlock().await?;

    Ok(())
}
```

## One client for the whole program

`Client` is cheap to clone. All clones share the same connections. Create it once and give clones to your tasks.

The client reconnects by itself if the connection is lost. When the last clone is dropped, the connections are closed.

## Errors

Every call returns `redissun::Result`. `Error` can get new cases in future versions, so always add a `_` case when you match it.

```rust
match lock.try_lock().await {
    Ok(Some(guard)) => guard.unlock().await?,
    Ok(None) => println!("busy"),
    Err(error) => return Err(error),
}
```
