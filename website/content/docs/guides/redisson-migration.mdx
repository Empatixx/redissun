## Naming

| Redisson | redissun |
|---|---|
| `RBucket` | `Bucket` |
| `RMap` | `HashMap` |
| `RList` | `Vec` |
| `RDeque`, `RQueue` | `VecDeque` |
| `RSet` | `HashSet` |
| `RLocalCachedMap` | `LocalCachedMap` |
| `RLock` | `Lock` |
| `RReadWriteLock` | `RwLock` |
| `RFairLock` | `FairLock` |
| `RScoredSortedSet` | `SortedSet` |
| `RPriorityQueue`, `RPriorityBlockingQueue` | `SortedSet` with `pop_first_wait` |
| `RFencedLock` | `FencedLock` |
| `RedissonMultiLock` | `MultiLock` |
| `RDelayedQueue` | `DelayedQueue` |
| `RBitSet` | `BitSet` |
| `RHyperLogLog` | `HyperLogLog` |
| `RBloomFilter` | `BloomFilter` |
| `RBlockingQueue` | `VecDeque` with `pop_front_wait` |
| `RMapCache` | `HashMapCache` |
| `RSetCache` | `HashSetCache` |
| `RTopic` | `Topic` |
| `RStream` | `Stream` |
| `RGeo` | `Geo` |
| `RAtomicLong` | `AtomicI64` |
| `RSemaphore` | `Semaphore` |
| `RCountDownLatch` | `CountDownLatch` |
| `RRateLimiter` | `RateLimiter` |
| `redisson.getMap("x")` | `client.hash_map("x")` |
| `redisson.getList("x")` | `client.vec("x")` |
| `redisson.getDeque("x")` | `client.vec_deque("x")` |
| `redisson.getSet("x")` | `client.hash_set("x")` |
| `redisson.getLock("x")` | `client.lock("x")` |

## Bucket

| Redisson | redissun |
|---|---|
| `set(v)` | `set(&v)` |
| `set(v, ttl)` | `set_ex(&v, ttl)` |
| `get()` | `get()` |
| `trySet(v)` | `set_nx(&v)` |
| `getAndSet(v)` | `get_set(&v)` |
| `getAndDelete()` | `get_del()` |
| `compareAndSet(e, n)` | `compare_and_set(&e, &n)` |

## HashMap

| Redisson | redissun |
|---|---|
| `put(k, v)` | `insert(&k, &v)` |
| `get(k)` | `get(&k)` |
| `remove(k)` | `remove(&k)` |
| `containsKey(k)` | `contains_key(&k)` |
| `size()` | `len()` |
| `putAll(m)` | `extend(entries)` |
| `getAll(keys)` | `get_many(&keys)` |
| `putIfAbsent(k, v)` | `insert_nx(&k, &v)` |
| `addAndGet(k, d)` | `incr_by(&k, d)` or `incr_by_float(&k, d)` |
| `keySet()`, `values()`, `entrySet()` | `keys()`, `values()`, `iter()` as streams |

`putIfAbsent` returns the existing value in Java. `insert_nx` returns whether the entry was inserted.

## Vec

|---|---|

|---|---|
| `readLock().lock()` | `read()` |

## HashMapCache

| Redisson | redissun |
|---|---|
| `put(k, v)` | `insert(&k, &v)` |
| `put(k, v, ttl, unit)` | `insert(&k, &v).ttl(ttl)` |
| `putIfAbsent(k, v)` | `insert_nx(&k, &v)` |
| `remainTimeToLive(k)` | `entry_ttl(&k)` |

Both delete expired entries with a background task. `put(k, v, ttl, unit, maxIdle, unit)` is `insert(&k, &v).ttl(ttl).max_idle(idle)`. `setMaxSize(n, mode)` is `set_max_size(n, mode)`, and `addListener(...)` is `events()` followed by `recv()`.

| Redisson | redissun |
|---|---|
| `trySetRate(mode, rate, interval, unit)` | `try_set_rate(type, rate, interval)` |
| `setRate(...)` | `set_rate(...)` |

## Behavioural differences

- The lock owner is a client and a tokio task, not a thread.
- Unlocking goes through a guard value. Unlocking something you do not hold is `Error::LockNotHeld` instead of an `IllegalMonitorStateException`.
- Values use a serde codec rather than Redisson's Java codecs, so data written by Redisson is not readable by redissun and the other way round.
- When a semaphore or latch changes, redissun wakes every waiter and each one tries again. Redisson wakes only as many as there are permits.
- The rate limiter reads the time from the Redis server. Redisson sends the time of the client.
- `RateLimiter` has no `keepAliveTime` setting yet.
