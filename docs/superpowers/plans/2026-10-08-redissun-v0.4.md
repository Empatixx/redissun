# redissun v0.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add `Topic`, blocking pops on `VecDeque`, `RwLock` and `HashMapCache`; bump to 0.4.0.

**Architecture:** `PubSub` entries get a broadcast sender for payloads (Topic). Blocking pops use a short-lived dedicated connection. `RwLock` is Lua over a writer hash, a readers set and one lease key per reader. `HashMapCache` is Lua over a hash plus an expiry sorted set, using server `TIME`.

**Tech Stack:** fred 10, tokio, serde, testcontainers.

**Spec:** `docs/superpowers/specs/2026-10-08-redissun-v0.4-design.md`

## Review Focus

- A Topic subscriber never misses a message published after `subscribe` returned.
- Blocking pops: a waiting pop does not stall other commands; no element is delivered twice.
- RwLock: a crashed reader's lease ends while other readers keep renewing; writer excludes everyone.
- HashMapCache: an expired entry is never returned, even without eviction; `insert` replaces an old limit.
